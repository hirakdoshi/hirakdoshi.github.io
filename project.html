Site history

v1.5.1 August 25, 2026
  • Added a "View Changelog" trigger in the footer, opening the changelog itself as a modal instead of a page section
  • Fixed scrollbars visually breaking the border corner on card lists and modal boxes
  • Changelog list now uses standard bullets and justified text, matching the rest of the site
  • Redesigned the mobile footer: better spacing, bordered pill buttons for Contact and Changelogs
v1.5.0 August 25, 2026
  • Reading-time estimates added to every Notebook post, computed live from actual word count (code blocks excluded, so estimates stay accurate as posts change)
  • Real, working contact form — opens in the same blurred modal used elsewhere on the site, submits via Formspree, replacing the old mailto: link
  • Print-friendly stylesheet: a clean, black-on-white version of every page for printing or exporting to PDF
  • Light/dark mode toggle added site-wide, with the choice remembered across pages and future visits
v1.4.0 August 23, 2026
  • Reworked the Projects page: removed Certifications, dropped membership ID numbers, reordered content so GitHub Projects sits above Memberships
  • Mobile fix: Memberships and GitHub Projects now render as a proper 2-column grid on phones instead of a single stacked list
  • GitHub project cards now show live, auto-fetched creation dates from the GitHub API and sort themselves newest-first automatically
v1.3.0 August 19–22, 2026
  • Learning Linux — II: The Filesystem Hierarchy — a plain-language tour of /etc, /var, /opt, /bin, /usr and the rest
  • Learning Linux — III: Basic Commands, Files & Navigation — 15 real, tested commands with actual terminal output
  • Copy-to-clipboard buttons added on every code block, with a clear visual distinction between commands and their output
v1.2.0 August 17–18, 2026
  • Finalized the Notebook post-card design: bordered cards, a "Share" button with clipboard copy, consistent published-date formatting
  • Built month/year grouping for Notebook entries, with a custom tree connector — trunk line, dot, and curved branch — linking each post to its month
  • Began the Learning Linux series — Part I: Manual Partitioning During Installation, covering both single-OS and dual-boot setups, including a real BitLocker snag encountered along the way
  • Diagnosed and fixed a tablet-specific layout bug that caused the page to wiggle and misalign on mid-sized screens
v1.1.0 August 16, 2026
  • Introduced the Notebook section — a running journal separate from the formal Research and Teaching pages
  • Drafted the first long-form post (an FSL/MRtrix3 setup guide), later put on hold to make room for a different series
  • Fixed the site favicon and corrected broken chess piece rendering
v1.0.0 August 15, 2026
  • Complete ground-up redesign: dark charcoal, mono/terminal-inspired dashboard layout, replacing the original site entirely
  • Built Home, Research, Teaching, and Projects pages
  • "Read Along" — a live research-paper feed pulling from CrossRef, rotating across Mathematical Imaging, Motion & Optical Flow, and Diffusion MRI
  • A real, playable daily Lichess puzzle, solvable directly on the site with move validation and an "Analyze on Lichess" link
  • SJR quartile badges added to publications, color-coded and linked to each journal's SCImago page
