Setting up FSL and MRtrix3 on Linux

Published on August 16, 2026 · …

This blog will guide you about setting up FMRIB Software Library (FSL) and MRtrix3 on linux.

FSL

Don't fight the dependencies by hand — just use the installer script:

wget https://fsl.fmrib.ox.ac.uk/fsldownloads/fslinstaller.py
python3 fslinstaller.py

Let it finish. Killing it halfway through is how you end up with a half-broken FSL that nothing quite explains. Default path (/usr/local/fsl) is fine unless you have a reason not to.

If fsl isn't found afterward, it's usually just that these never got sourced:

export FSLDIR=/usr/local/fsl
source ${FSLDIR}/etc/fslconf/fsl.sh
export PATH=${FSLDIR}/bin:${PATH}

MRtrix3

Build from source — the multi-shell CSD stuff moves too fast for packaged releases to keep up:

git clone https://github.com/MRtrix3/mrtrix3.git
cd mrtrix3
./configure
./build
./set_path

Everyone forgets ./set_path. Skip it and dwi2fod just says "command not found," which tells you nothing about what actually went wrong.

Making sure they agree with each other

Once you've got a DWI scan converted to NIfTI (say, via dcm2niix) — a dwi.mif, plus a bvecs/bvals pair — it's worth checking that FSL's and MRtrix3's gradient conventions actually line up before you trust either tool with real data:

mrinfo -fslgrad bvecs bvals dwi.mif -export_grad_mrtrix grad.b
mrinfo grad.b -export_grad_fsl check.bvec check.bval
diff bvecs check.bvec

No output from that last line, you're fine.
